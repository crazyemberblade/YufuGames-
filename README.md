# YufuGames v2

Static HTML/CSS/JavaScript prototype for GitHub Pages.

## Files
- index.html — page structure
- style.css — responsive UI
- games.js — local game requirement database
- app.js — compatibility logic
- hero.jpg — landing-page image

## GitHub Pages
Upload all files to the repository root, then:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

No backend is required.
